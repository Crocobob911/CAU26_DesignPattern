# 수동 테스트 체크리스트 — 원본 기능 유지 확인

리팩터링 **전**(`v0-original`)과 **후**(최종 제출본)에 같은 절차를 수행해,
기존 Life Game 기능이 그대로 동작하는지 확인한다.
JUnit으로 확인할 수 없는 화면·메뉴·파일 대화상자 동작이 대상이다.
(보드 규칙·패턴 진화·Clear·Store/Load 데이터는 `OriginalBehaviorTest`가 자동으로 확인함)

## 수행 방법

1. 실행: `.\gradlew.bat run` (macOS/Linux: `./gradlew run`)
2. 각 항목의 절차를 수행하고 결과 칸에 `✅` / `❌`(+메모)를 적는다.
3. 📷 표시 항목은 스크린샷을 `docs/screenshots/v0/<ID>.png` (리팩터링 후에는 `final/<ID>.png`)로 저장한다.
4. 결과가 기대와 다르면 원본에서는 "원본 동작"으로 메모만 남긴다. 리팩터링 후에는 원본과 다르면 버그로 Issue를 등록한다.
